# SANS FUTURE — AI Interface Demo

A static, responsive futuristic UI prototype with:
- CSS 3D-style glowing orb and orbit animations
- Local simulated chat (not connected to a real AI model)
- Basic DOM accessibility checks
- Animation pause/resume and viewport-size check
- Mobile-friendly layout and reduced-motion support

## Run locally
Open `index.html` in a modern browser.

## Deploy
This is a static site and can be deployed through GitHub Pages or Vercel. A hosting deployment is not confirmed by adding files to GitHub; check the hosting dashboard or configure the project there.

## Important limitations
- Chat replies are predefined demo responses.
- UI scan checks only a few DOM attributes; it is not a full bug scanner or security audit.
- No backend, authentication, database, or external API is included.
